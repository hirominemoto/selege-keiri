# 決まったこと（業務ルール）

ひろみ（根元）の回答と、ペチちゃんのレビューで決まった業務ルールの一覧。実装はこのルールに合わせる。
決まっていないことは、仮のルールで固めずに聞く（最後の「まだ決めていないこと」）。
企業ごとの個別の事情は、claude.ai プロジェクトの引き継ぎメモにある（取引先の実データなので GitHub には置かない）。

最終更新：2026-10-28

## 運用

| 項目 | 決まったこと |
| --- | --- |
| 開始 | 11月請求分から。それまでの旧Excelは南條さんが担当 |
| 使う人 | 根元・南條さん・セレッジ担当の3人とも、すべての操作ができる。社長は見るだけ |
| 役割 | セレッジ担当：柏木さんが入力していたのと同じ請求内容を入力。南條さん：郵送分の請求書と封筒を印刷して投函。根元：受け取った請求書の登録と総務の受付、毎月の固定費の入力 |
| 承認 | 社長の承認は不要。「確定」の手順も作らない（セレッジで決まったものを請求するだけ） |
| 年度 | 7月決算。8月から新年度 |

## 請求

| 項目 | 決まったこと |
| --- | --- |
| 流れ | 請求書は「下書き → 送付OK → 送付済み」。下書きは自由に直せる。送付OKで内容が固まり、番号と売上ができる |
| 送付OKのあとに直す | 送る前：理由を書いて送付OKを取り消し、直して、もう一度確認して送付OK（番号はそのまま） |
| 送ったあとに直す | 同じ番号で訂正版を作る。前の版は「訂正済み（旧版）」として残る |
| 請求書番号 | 自動採番。「年度2桁＋月2桁-その月の連番」。2026年11月の1枚目は 2711-01（年度は終わる年の下2桁）。100枚目からは3桁 |
| 送り方 | 郵送／メール（セレッジ担当が直接送る）を、請求書ごとにその都度選ぶ。担当者が変わると変わることがあるため。企業の「いつもの送り方」は目安 |
| 請求のしかた | 契約ごとに「毎月（分割・月額）」「都度（請求するときだけ）」「1回だけ」。都度の契約は、請求のない月を未請求として扱わない |
| 回数 | セレッジ側でその都度決める。アプリは候補（取り込み時の回数とアプリの最大の大きいほう＋1）を出すだけ |
| 追加・訂正 | 「追加」「訂正」の請求依頼で扱う。元の依頼と理由が必須 |
| 金額が契約と違う | 色で目立たせるだけ。理由の入力は求めない |
| 売上の月 | 請求ベース（請求した月の売上） |
| 消費税 | 請求書ごとに1回計算。端数は切り上げ。立替金は「消費税がかからない」行 |
| 請求書のない売上 | 送付OKを通らずに売上にできる |
| 入金予定日 | 基本は翌月末。例外は担当者が入力時に決める |
| 書式 | 今のExcelと同じ並び。A4、角印、明細8行。立替金がある請求書だけ合計欄を「10％対象／消費税／対象外」に分ける |
| 封筒 | 長3。プリンターは Canon |
| 旧Excelの分 | 契約ごとに「Excelで請求済みの最後の◯月分」を持つ。11月分は10月末にExcelで請求済み |

## 支払い・収支

| 項目 | 決まったこと |
| --- | --- |
| 支出の置き場所 | 「支払い」と「月次の固定費」の2つだけ。家賃は支払い |
| 総務 | 総務を通す支出と、通さない支出（カード・引き落とし）がある。通さないものは総務依頼日なしで登録 |
| 顧客への返金 | 支出として数える。売上は減らさない |

## ペチちゃんのレビューの6条件（2026-10-28）

「確定」をなくし、送付OK（セレッジ側）と発送・送付済み（送付担当）の2段階にする条件。

1. 入力途中は自由に保存・修正できる
2. 送付OK時点の請求内容を固定し、変更時は再確認を必要とする
3. 送付OKの重複操作で請求書・売上が二重登録されない
4. 請求書なしの売上は送付OKを必要としない
5. 郵送とセレッジ担当者によるメール送付を区別する
6. 操作した人と日時を記録する

どう満たしたかは `tests/db.test.mjs` の「条件1〜6」のテストを見る。

## まだ決めていないこと

- 送付OKを押せる人と、具体的な画面操作（セレッジの新しい担当者と決める）
- 請求書PDFを誰が作るか、セレッジ側の確認の流れ（同上）
- 立替金の行に付ける言葉：「非課税」のままか「対象外（立替金）」か（税理士に確認）
- 請求状況の表を何か月分見せるか（案：過去12か月＋先2か月）、請求漏れの警告をいつから出すか
- 請求書のない売上にも消費税を計算するか（今は手入力、初期値0）
- 回数が品名にない契約は、回数を持たない扱いでよいか
- ◯月分が契約期間外のとき、止めるか注意だけか（今は止めず、請求状況で「対象外」と出るだけ）
